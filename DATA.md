## Synthetic samples are benign

* "PE", "ELF" and "OLE" fixtures are header stubs (1 KiB PE header with section names,
  64-byte ELF identification header, OLE2 signature + zeroed sector) followed by
  marker strings. They contain no executable code and cannot run.
* Script fixtures (PowerShell, PHP, shell) reproduce the *shape* of a technique with
  harmless payloads: the encoded PowerShell command decodes to
  `Write-Output 'yaraci lab fixture'`; the PHP `eval(base64_decode(...))` decodes to
  `echo "yaraci lab fixture";`; download URLs use the reserved `.invalid` TLD or the
  TEST-NET-3 documentation range (203.0.113.0/24) and never resolve to a real host.
* The "ransom note" is labelled as a tabletop-exercise fixture.
